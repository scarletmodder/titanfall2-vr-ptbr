Tradução para português do Brasil dos textos do mod Titanfall 2 VR, jogada no headset, sem problema no conteúdo em PT-BR.

**Para a versão 1.0.25 do mod.** 196 textos traduzidos, nenhum pendente.

**Como instalar:** instale o mod pelo [instalador oficial](https://github.com/CircuitLord/CircuitLordVRModInstaller), feche o jogo, abra o `Instalador-Traducao-PTBR-Mod-Titanfall2VR-v1.0.1.exe` e siga as telas. O [guia de instalação](https://github.com/scarletmodder/titanfall2-vr-ptbr/blob/main/docs/installation.md) mostra cada tela, inclusive a desinstalação.

**Para voltar ao inglês:** desinstale "Tradução PT-BR do mod Titanfall 2 VR" pela lista de aplicativos do Windows. Os textos originais voltam para o lugar.

**O instalador não tem assinatura digital.** O Windows pode avisar que o arquivo é desconhecido. Você pode conferir o hash abaixo ou compilar pelo código.

A tela inicial de calibração dos braços continua em inglês, porque as frases dela são uma imagem do mod.

Projeto de fã, sem vínculo com EA, Respawn ou CircuitLord. Esta release não contém arquivos do jogo nem do mod.

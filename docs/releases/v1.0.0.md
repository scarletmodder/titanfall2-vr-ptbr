Primeira versão da tradução para português do Brasil dos textos do mod Titanfall 2 VR.

**Para a versão 1.0.25 do mod.** 196 textos traduzidos, nenhum pendente: menu de configurações de VR, avisos de interação, dicas do tutorial, menu de pausa, escolhas de diálogo e menu principal.

Como usar: instale o mod pelo [instalador oficial](https://github.com/CircuitLord/CircuitLordVRModInstaller), feche o jogo, abra o `Titanfall2VR-PTBR.exe` e escolha `[1]`. A opção `[2]` devolve os originais. Se você usou o pacote antigo "Titanfall 2 VR em Português", desinstale esse pacote antes.

O executável não tem assinatura digital, então o Windows pode avisar. Confira o hash abaixo e veja a seção Segurança do README.

**Limitações:** os acentos em texto de interface e a tradução em si ainda não foram confirmados dentro do jogo. Se algo sair errado na tela, abra uma issue.

Projeto de fã, sem vínculo com EA, Respawn ou CircuitLord. Esta release não contém arquivos do jogo nem do mod.
